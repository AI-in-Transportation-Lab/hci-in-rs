## Worked Example 1: The Affordable Glance

Closed-form kinematics for the longest off-road glance a driver can afford at a given speed and sight distance, compared with the 2-second glance guideline.

## Run

```bash
python scripts/run_all.py --chapter 1      # from the repository root
```

Outputs (figures, printed results) are written to `outputs/ch01/`.
